# winding_fill — 非零环绕多边形/二次曲线填充模块

为离线字体栅格内核提供的**可复用**模块：

1. 输入由线段与二次 Bézier 组成的至多 20 条闭合轮廓（有理坐标），在不
   大于 64×64 的画布上，按**每像素固定 4×4 子采样**、对水平射线用
   **半开 y 规则**累加带方向交点，以 **nonzero winding（非零环绕）**
   规则决定每个子样本是否被覆盖，输出 17 级灰度覆盖值（k/16,
   k=0..16）并允许逐子样本查询有符号环绕数。
2. 对**两个简单、无洞、有理坐标、仅直线段**的闭合轮廓，提供精确的
   **并（union）/ 交（intersection）/ 差（difference）**布尔运算，
   结果仍是可直接栅格化的 `Contour` 元组；运算全程使用
   `fractions.Fraction` **精确有理算术**，相切、重合边、T 形接触与
   包含关系均无容差精确处理，并拒绝自交输入。

全部核心算法从零实现，**不调用任何字体/绘图库或第三方同类实现**。

## 运行环境

- Python **3.14.7**（标准库；3.10+ 的语法亦可运行，但以 3.14.7 为准）
- Linux 原生运行，**无需安装任何第三方依赖**，无需网络 / 账号 / 密钥 /
  硬件 / 数据库 / 中间件 / 云 API / Docker。

## 公开接口

```python
from winding_fill import (

    rasterize_raw,                  # 校验 + 栅格化一步完成
    # 布尔运算（本次新增）：
    UNION, INTERSECTION, DIFFERENCE,     # 操作名常量
    boolean_union, boolean_intersection, boolean_difference,
    boolean_op_raw,                 # 原始 dict 版布尔入口

    signed_area,                    # 精确有符号面积（Fraction）

    SUBSAMPLES,      # = 4（契约常量）
```

### 布尔运算（v1.1 新增）

```python
result = boolean_union(a, b)          # a, b 均为简单直线 Contour
result = boolean_intersection(a, b)
result = boolean_difference(a, b)     # a \ b
result.contours   # tuple[Contour,...]：可直接喂给 rasterize
result.area       # Fraction 精确面积（外 CCW + 内 CW 环的有符号面积之和）
result.op         # "union" / "intersection" / "difference"
```

- **输入契约**：恰好两个参数，每个是**一条**简单闭合直线轮廓——无自交、
  无自身顶点重复/接触、无自身重合边（直线上的共线额外顶点允许）。含二次
  Bézier 的轮廓被**拒绝**（曲线弧不是有理多边形边界，展平会引入近似，
  本库永不静默近似）；方向不限（CW/CCW 均可）。
- **非零环绕规则保持不变**：面内判定为“有符号环绕数 ≠ 0”；因此
  `difference(a,b)` 擦除 b 覆盖的区域，语义与栅格化器一致。
- **结果形态**：外边界环 CCW、洞环 CW；环起点规范为字典序最小顶点；
  零面积接触（点接触、边重合处）不会产生退化环；点接触相连的两个区域
  作为两个独立简单环返回。
- **空结果**：交集/差集为空时返回的 `BooleanResult.contours` 为空元组
  `()`、`area=0`。注意现有栅格化器要求至少一条轮廓，所以对空结果调用
  `rasterize(result.contours, ...)` 会按既有契约抛 `InvalidInputError`；
  调用方按空结果处理即可。
- **原始数据入口** `boolean_op_raw(raw_a, raw_b, op)`：每个参数可传一条
  轮廓的段列表，也可传单元素轮廓列表（同 `parse_contours` 的形态）；
  两个输入**先完整校验再计算**，任一非法则整体抛错、无半更新状态。
- **精确性**：布尔核心的交点、面探针与面积全程 `Fraction`；仅在最后构造
  `Contour` 时把精确坐标转成 `float` 供既有数据结构与栅格化器使用。因此
  **面积始终精确**；栅格化结果仅在子样本恰好压在由非二进制有限有理交点
  （如 23/3）形成的边界上时，可能因双精度 ~1e-15 舍入翻转单个子样本，
  这与既有曲线求根的误差口径一致，测试中所有这类翻转都被证明距离精确
  边界 < 1e-9。

### 数据结构

- `Point(x, y)`、`Line(p0, p1)`、`Quad(p0, c, p1)`（一个控制点的二次
  Bézier）、`Contour(segments)`，均为冻结 dataclass。
- 轮廓**几何闭合**：最后一段终点必须与第一段起点完全相等（按输入值精确
  比较）；相邻段必须首尾相接。没有独立的“方向”标志——方向完全由坐标顺序
  决定，反转整条轮廓即反转其环绕贡献。
- 原始数据格式（`parse_contours` / `rasterize_raw`）：

  ```python
  [                                 # 1..20 条轮廓
    [                               # 一条轮廓 = 段列表（>= 3 段）
      {"type": "line", "p0": {"x": 1, "y": 1}, "p1": {"x": 5, "y": 1}},
      {"type": "quad", "p0": {...}, "c": {"x": 3, "y": 0}, "p1": {...}},
      ...
    ],
  ]
  ```

- 便捷构造：`build_contour([(x0,y0), ...], quads=((边序号, cx, cy), ...))`
  自动把顶点链闭合（末点连回首点），可用 `quads=` 指定某条边为二次曲线。

### 结果查询

`result = rasterize(contours, width, height)` 返回 `CoverageResult`：

- `result.levels`：行主序元组 `levels[py][px] ∈ {0,...,16}`，被覆盖子样本
  数；`py=0` 为**底部**一行（坐标系 y 向上，像素 `(px,py)` 覆盖
  `[px,px+1]×[py,py+1]`）。
- `result.windings[py][px]`：16 个有符号环绕数，索引 `j*4+i`
  （`i`,`j` ∈ 0..3 为子样本列/行）。
- `coverage_at(px, py) -> float`：`k/16`。
- `windings_at(px, py) -> tuple[int,...]`：16 个环绕数。
- `winding_at(px, py, i, j) -> int`：单个子样本的有符号环绕数。

子样本 `(i,j)` 位于
`(px+(2i+1)/8, py+(2j+1)/8)`（像素中心 4×4 网格）。

## 输入上限与错误语义（接口边界）

| 项目 | 边界 |
|---|---|
| 轮廓数 | 1..**20** |
| 画布边长 | 整数 1..**64** |
| 每条轮廓段数 | ≥ 3（无上限，但坐标受下面限制） |
| 坐标绝对值 | ≤ **1024** |
| 数值 | int/float；**NaN、±Infinity 一律拒绝**；`bool` 不算数值、整数参数拒绝 `bool` |
| 结构 | 必须闭合、首尾相接；零长度直线、端点重合的二次曲线被拒绝（方向无定义） |

- 所有异常都继承 `WindingFillError`；非法输入抛 `InvalidInputError`
  （同时是 `ValueError`），错误消息带**可定位**路径，如
  `contours[2].segments[1].p0.x: NaN and Infinity are not accepted`
  （机器可读位置在 `exc.location`）。非法输入**不静默纠正**。
- 批量操作先完整校验、后计算；任一轮廓非法则整体抛错，不产生部分结果，
  不存在“已说明之外的部分变更”。
- 本模块没有“搜索/求解预算”这一类资源概念（几何求交为闭式/确定次数
  迭代），因此不存在“预算耗尽 vs 证明无解”的歧义；无解情形（如轮廓外）
  是正常结果 0，而不是错误。

## 算法与设计取舍

1. **y 单调拆分**：直线天然单调；二次 Bézier 的
   `y(t)=a t²+b t+y0` 在内驻点 `t*=-b/(2a)` 处拆成至多 2 段，使每段对 y
   严格单调或水平。
2. **半开 y 规则**：对每条子样本水平线 `sy`，单调段端点
   `lo<hi` 时按 `lo ≤ sy < hi` 计一次——共享顶点的两条邻边恰有一条计入，
   不重不漏；水平段显式不计。方向：上行 +1、下行 −1。
3. **二次曲线求交**：在单调段上解 `y(t)=sy`（求根公式），单调段保证根
   唯一；控制点与端点重合的退化二次曲线等价为直线，按直线精确处理。
4. **切点确定性**：曲线 y 极值由 `y(t*)` 一次算出，相邻两段共用同一
   float 极值：要么两段都计入（−1/+1 成对抵消），要么都不计入，不依赖
   容差。
5. **环绕累加**：交点按 x 排序后做有符号后缀和；子样本点的环绕数为其
   右侧（`x ≥ sx`，点恰在边上按内部处理）所有交点方向之和；`winding≠0`
   即覆盖。
6. **坐标系**：x 向右、**y 向上**，与字体 EM 网格习惯一致；渲染为图像时
   调用方自行翻转行序。
7. **布尔运算（精确有理平面排列）**：见
   `winding_fill/boolean.py`。把两条轮廓的每条边在所有相互交点（正交
   交叉、T 接、共线重叠端点）处细分；重合的细分边合并、保留每条输入边
   的有向贡献；构造半边排列，按精确的 CCW 极角序在每个顶点“左转/右转”
   枚举面环；在每个面环一条边中点沿**精确左法向**取探针，走到第一个任何
   边界特征之前的半程点，对原始轮廓做精确 Fraction 射线环绕数查询得到
   `(wa, wb)` 标签（一个面有洞时外环/洞环标签相同，无需合并环）；按
   `wa≠0` / `wb≠0` 选择并/交/差面，再沿选中面的边界扇区追踪结果环，在
   点接触（figure-eight）处拆成独立简单环、消去共线顶点，最后规范为
   外 CCW / 内 CW。输入先做简单性校验（逐对边精确求交，拒绝自交/自触/
   自身共线重叠与零面积环），再开始任何计算。

### 浮点与误差口径（明确，不用宽容差掩盖边界）

- 覆盖级别 `levels` 与环绕数 `windings` 是**离散判定量**：测试对直线几何
  用 `fractions.Fraction` **精确有理**参考逐子样本比对（必须**完全相等**，
  不是“近似”）；对含二次曲线的几何用 60 位 `decimal.Decimal` +
  130 次二分求根（约 1e-39）的独立参考比对（**完全相等**）。参考实现
  位于 `tests/independent_reference.py`，**不导入被测核心**。
- 唯一使用 float 的地方是曲线求根的舍入：核心为 IEEE-754 双精度。测试
  坐标刻意取在 1/8 网格上，而 Decimal 参考以 ~1e-39 精度判定；当真实交点
  与某子样本 x 坐标的距离小于双精度舍入（~1e-15，乘以 ≤1024 的坐标量级）
  时，两侧判定一致。也就是说：**边界判定没有人为容差**；误差仅来自双精度
  求根本身（相对误差约 1e-15 量级），切点/顶点等退化情形由上面第 4 点的
  同一值共享机制消除二义性。
- `coverage_at` 是精确的 `k/16`（k 为整数 0..16），不产生其它浮点误差。
- **布尔运算**：交点与面积为严格 `Fraction` 精确值（`BooleanResult.area`
  即 `Fraction`）。唯一舍入发生在最后把结果顶点转成 `float` 以复用现有
  `Contour` 数据结构；因此当精确交点（如 23/3）与 1/8 子样本格点的距离
  在双精度 ~1e-15 内时，栅格化单个子样本可能翻转。测试对每个这样的
  翻转都验证其与精确边界距离 < 1e-9，并另有**全程 Fraction、不经过
  float/栅格化器**的区域成员判定测试（在 1/2 格点枚举核对）。

## 已知限制 / 非目标

- 仅实现本题契约的数学子集：线段 + 二次 Bézier；**不支持**三次及以上
  Bézier、圆弧、可变子采样率（固定 4×4）、子像素平移 hinting、
  anti-alias 滤波（覆盖率就是盒子滤波的 k/16）、奇偶(even-odd)规则。
- **布尔运算仅适用于两个简单、无洞、仅直线段且坐标可精确表示为
  二进制有理的输入**；**不**做以下事项：三个及以上轮廓的复合布尔、
  带洞/自交/自触轮廓的修复或布尔、含二次曲线轮廓的布尔（拒绝而非
  展平近似）、XOR 等未列操作、结果写回原始对象。复杂（段数很多）
  输入的排列构建最坏为边数平方级；本迭代验证用的小规模简单多边形
  均毫秒级完成。
- 不宣称与任何行业标准（TrueType/OpenType scan-converter、SVG、
  D 算法细节、Porter-Duff 合成等）完整兼容；只对本文档描述的契约负责。
- 栅格化器本身仍可接受自交/重叠轮廓（nonzero winding 的直接数学结果，
  测试含蝴蝶结用例）；**自交拒绝仅发生在布尔入口**——简单性是布尔
  契约特有的前置条件，没有为其他入口改变行为。
- 轮廓非常复杂时（段数很多）时间随“子样本行 × 段数”线性增长；上限
  规模（20 条曲边轮廓、64×64）实测亚秒级。

## 演示说明

`python demo.py` 真实计算两部分内容：

1. 一个 19×13 字形（CCW 曲边外框 + 与其重叠的 CCW 矩形 + CW 曲边洞），
   打印灰度图与 4 个固定子样本环绕数（普通区域 +1、重叠区域 +2、洞内
   0、外部 0）；
2. 两个简单有理多边形（[0,4]² 与 [2,6]² 方块）的并/交/差，打印精确面积
   （28/4/12，含容斥恒等式）、并集的实际栅格化图，以及包含（差集=外环
   +CW 洞、洞心栅格化为空）与边相切（交集零面积、无结果环）两个边界
   关系；

随后实际触发拒绝：布尔入口拒绝自交蝴蝶结轮廓与含二次曲线轮廓，原有
栅格化入口拒绝 NaN 坐标（定位到具体字段）与 `bool` 冒充整数画布宽度。
无 sleep、无预录结果，全程序约 0.06 秒。
