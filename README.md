# winding_fill — 非零环绕多边形/二次曲线填充 + 精确布尔运算模块

为离线字体栅格内核提供的**可复用**模块。两部分能力：

1. **非零环绕栅格化**：输入由线段与二次 Bézier 组成的至多 20 条闭合轮廓
   （有理坐标），在不大于 64×64 的画布上，按**每像素固定 4×4 子采样**、
   对水平射线用**半开 y 规则**累加带方向交点，以 **nonzero winding（非零
   环绕）** 规则决定每个子样本是否被覆盖，输出 17 级灰度覆盖值
   （k/16, k=0..16）并允许逐子样本查询有符号环绕数。
2. **精确布尔集合运算**（本次新增）：对两组**简单、无洞、仅直线**的有理
   坐标轮廓做**并、交、差**，结果仍以 nonzero winding 表达（外环 CCW、
   洞 CW），可直接回灌栅格化。正确处理相切、（部分）重合边与包含关系；
   拒绝自交输入。

全部核心算法从零实现，**不调用任何字体/绘图库或第三方同类实现**。

## 公开接口

```python
from winding_fill import (
    Point, Line, Quad, Contour,      # 不可变数据结构（frozen dataclass）
    build_contour,                  # 顶点链 -> Contour 的便捷构造器

    rasterize_raw,                  # 校验 + 栅格化一步完成

    union, intersection, difference,# 并 / 交 / 差
    boolean,                        # 同上，op 取 "union"/"intersection"/"difference"
    boolean_raw,                    # 原始 dict 数据一步校验 + 布尔
    BooleanResult,                  # 布尔结果（轮廓 + 精确面积）
    polygon_area,                   # 单条直线轮廓的精确有符号面积

    # --- 异常与契约常量 ---
    InvalidInputError, SelfIntersectionError, WindingFillError,
    SUBSAMPLES,      # = 4（契约常量）
    MAX_CONTOURS,    # = 20
    MAX_CANVAS,      # = 64
    MAX_COORD_ABS,   # = 1024（允许的坐标绝对值上限）

```

### 布尔集合运算（并 / 交 / 差）

```python
result = union(a, b)          # a、b 各为一个 Contour 或 Contour 列表
result = intersection(a, b)
result = difference(a, b)     # a − b
result = boolean(a, b, "union")
result = boolean_raw(raw_a, raw_b, "difference")  # dict 原始数据入口
```

- 输入：两组（1..20 条）**简单、无洞、仅由 `Line` 组成**的闭合轮廓；
  每个操作数可以是单个 `Contour` 或其列表，与 `rasterize` 一致。
- 输出 `BooleanResult`：
  - `result.contours`：自然定向的结果轮廓元组（**外环 CCW 为正、洞 CW
    为负**），可直接传给 `rasterize`；零面积结果（如不相交的交）为 `()`。
  - `result.polygons`：同样的环，但为**未取整的精确有理顶点链**
    （`tuple[tuple[Fraction, Fraction], ...]`，开链、末点不重复）。
    交点产生的无理/分数顶点（如斜边相交得到的 `6/5`）原样保留。
  - `result.area`：精确总面积（`fractions.Fraction`，洞已扣减）；
    `result.contour_areas`：每个环各自的有符号精确面积。
  - `result.is_empty`：结果是否为零面积空集；`result.area_float`：转 float。
  - `result.rasterize(width, height)`：直接对结果做 nonzero winding
    栅格化（空集返回全零画布，而不是因“无轮廓”报错）。
- 语义即集合：并 = `wa≠0 或 wb≠0`，交 = 两者都 `≠0`，差 = `wa≠0 且
  wb==0`，其中 wa/wb 是两侧轮廓在该点的精确有符号环绕数。因此结果
  轮廓回灌栅格化后，与“两操作数逐子样本做集合组合”**逐子样本完全相等**。
- 对操作数整体反转方向不敏感：输入轮廓可顺可逆，输出方向都规范为
  外正内负。

### 数据结构

- `Point(x, y)`、`Line(p0, p1)`、`Quad(p0, c, p1)`（一个控制点的二次
  Bézier）、`Contour(segments)`，均为冻结 dataclass。
- 轮廓**几何闭合**：最后一段终点必须与第一段起点完全相等（按输入值精确
  比较）；相邻段必须首尾相接。没有独立的“方向”标志——方向完全由坐标顺序
  决定，反转整条轮廓即反转其环绕贡献。
- 原始数据格式（`parse_contours` / `rasterize_raw`）：

  ```python
  [                                 # 1..20 条轮廓
    [                               # 一条轮廓 = 段列表（>= 3 段）
      {"type": "line", "p0": {"x": 1, "y": 1}, "p1": {"x": 5, "y": 1}},
      {"type": "quad", "p0": {...}, "c": {"x": 3, "y": 0}, "p1": {...}},
      ...
    ],
  ]
  ```

- 便捷构造：`build_contour([(x0,y0), ...], quads=((边序号, cx, cy), ...))`
  自动把顶点链闭合（末点连回首点），可用 `quads=` 指定某条边为二次曲线。

### 结果查询

`result = rasterize(contours, width, height)` 返回 `CoverageResult`：

- `result.levels`：行主序元组 `levels[py][px] ∈ {0,...,16}`，被覆盖子样本
  数；`py=0` 为**底部**一行（坐标系 y 向上，像素 `(px,py)` 覆盖
  `[px,px+1]×[py,py+1]`）。
- `result.windings[py][px]`：16 个有符号环绕数，索引 `j*4+i`
  （`i`,`j` ∈ 0..3 为子样本列/行）。
- `coverage_at(px, py) -> float`：`k/16`。
- `windings_at(px, py) -> tuple[int,...]`：16 个环绕数。
- `winding_at(px, py, i, j) -> int`：单个子样本的有符号环绕数。

子样本 `(i,j)` 位于
`(px+(2i+1)/8, py+(2j+1)/8)`（像素中心 4×4 网格）。

## 输入上限与错误语义（接口边界）

| 项目 | 边界 |
|---|---|
| 轮廓数 | 1..**20** |
| 画布边长 | 整数 1..**64** |
| 每条轮廓段数 | ≥ 3（无上限，但坐标受下面限制） |
| 坐标绝对值 | ≤ **1024** |
| 数值 | int/float；**NaN、±Infinity 一律拒绝**；`bool` 不算数值、整数参数拒绝 `bool` |
| 结构 | 必须闭合、首尾相接；零长度直线、端点重合的二次曲线被拒绝（方向无定义） |

- 所有异常都继承 `WindingFillError`；非法输入抛 `InvalidInputError`
  （同时是 `ValueError`），错误消息带**可定位**路径，如
  `contours[2].segments[1].p0.x: NaN and Infinity are not accepted`
  （机器可读位置在 `exc.location`）。非法输入**不静默纠正**。
- 布尔运算额外抛 `SelfIntersectionError`（同样继承 `WindingFillError`
  与 `ValueError`）：任一操作数轮廓不是简单 Jordan 曲线——非相邻边相交或
  相切、相邻边在公共端点之外重叠/折回、顶点重复——都在任何结果构造**之前**
  拒绝；`exc.location` 定位到操作数一侧与轮廓序号（`a[0]` / `b[2]`），
  消息给出冲突的边对。布尔入口同样拒绝含二次 Bézier 的轮廓
  （本轮仅支持直线），该情形为 `InvalidInputError`。
- 批量操作先完整校验、后计算；任一操作数/轮廓非法则整体抛错，不产生部分
  结果、不修改输入对象，不存在“已说明之外的部分变更”。
- 本模块没有“搜索/求解预算”这一类资源概念（几何求交为闭式/确定次数
  迭代），因此不存在“预算耗尽 vs 证明无解”的歧义；无解情形（如轮廓外、
  不相交集合的交）是正常结果（空集/0），而不是错误。

## 算法与设计取舍

1. **y 单调拆分**：直线天然单调；二次 Bézier 的
   `y(t)=a t²+b t+y0` 在内驻点 `t*=-b/(2a)` 处拆成至多 2 段，使每段对 y
   严格单调或水平。
2. **半开 y 规则**：对每条子样本水平线 `sy`，单调段端点
   `lo<hi` 时按 `lo ≤ sy < hi` 计一次——共享顶点的两条邻边恰有一条计入，
   不重不漏；水平段显式不计。方向：上行 +1、下行 −1。
3. **二次曲线求交**：在单调段上解 `y(t)=sy`（求根公式），单调段保证根
   唯一；控制点与端点重合的退化二次曲线等价为直线，按直线精确处理。
4. **切点确定性**：曲线 y 极值由 `y(t*)` 一次算出，相邻两段共用同一
   float 极值：要么两段都计入（−1/+1 成对抵消），要么都不计入，不依赖
   容差。
5. **环绕累加**：交点按 x 排序后做有符号后缀和；子样本点的环绕数为其
   右侧（`x ≥ sx`，点恰在边上按内部处理）所有交点方向之和；`winding≠0`
   即覆盖。
6. **坐标系**：x 向右、**y 向上**，与字体 EM 网格习惯一致；渲染为图像时
   调用方自行翻转行序。

### 浮点与误差口径（明确，不用宽容差掩盖边界）

- 覆盖级别 `levels` 与环绕数 `windings` 是**离散判定量**：测试对直线几何
  用 `fractions.Fraction` **精确有理**参考逐子样本比对（必须**完全相等**，
  不是“近似”）；对含二次曲线的几何用 60 位 `decimal.Decimal` +
  130 次二分求根（约 1e-39）的独立参考比对（**完全相等**）。参考实现
  位于 `tests/independent_reference.py`，**不导入被测核心**。
- 唯一使用 float 的地方是曲线求根的舍入：核心为 IEEE-754 双精度。测试
  坐标刻意取在 1/8 网格上，而 Decimal 参考以 ~1e-39 精度判定；当真实交点
  与某子样本 x 坐标的距离小于双精度舍入（~1e-15，乘以 ≤1024 的坐标量级）
  时，两侧判定一致。也就是说：**边界判定没有人为容差**；误差仅来自双精度
  求根本身（相对误差约 1e-15 量级），切点/顶点等退化情形由上面第 4 点的
  同一值共享机制消除二义性。
- `coverage_at` 是精确的 `k/16`（k 为整数 0..16），不产生其它浮点误差。

## 布尔运算的算法与精确性

布尔运算（`winding_fill/boolean.py`）全部用 `fractions.Fraction`
**精确有理**计算，不使用任何浮点比较或容差：

1. **简单性证明（拒绝自交）**：逐对检查轮廓的边。非相邻边只要有任何
   接触（含只是相切、端点落在对方边上）即拒绝；相邻边只允许在公共端点处
   相接，在公共端点之外重叠或折返也拒绝；顶点不得重复。判定本身用的就是
   后面同一套精确求交，故“相交、相切、共线重叠”由统一代码区分。
2. **平面排布（arrangement）**：对两组边的每一对精确求交，记录各自边上的
   接触参数（横穿、端点接触、共线时给出重叠区间端点）。每条边在所有接触
   参数处切开；几何上重合的小边去重合并，得到一个规范平面直线图，其面是
   环绕数对 `(wa, wb)` 恒定的开区域。复杂度为边对数的 `O(E²)`，本轮规模
   （每侧 ≤20 条简单轮廓）实测毫秒级。
3. **符号扰动数环绕数**：每个面取边中点沿左法线方向移动一个正无穷小
   `ε` 的代表点，用对偶数 `a+b·ε`（`ε²=0`）精确求值。代表点恰好落在边或
   顶点水平线上时，`ε` 分量给出确定的归属，所以**相切不靠容差**，与栅格化
   侧“半开 y + 点在边上算内部”的口径一致。
4. **选面与描边**：按操作谓词选出面（并 `wa≠0 或 wb≠0`；交两者皆非零；
   差 `wa≠0 且 wb==0`）。每条排布边恰有一个有向半边作为结果边界（左侧面
   被选、右侧面不被选的那一方向）。在顶点处从入边反方向沿**顺时针**扫过
   完整出射环取第一条边界边——这是“面集合边界”的标准规则，凸/凹角都成立，
   且在点相切处不会把两个仅共点的环缝到一起。内部点相切产生的“套索”游走
   在重复顶点处拆成各自简单的环；直线段上的共线冗余顶点会被删除。
5. **方向与面积**：结果环天然按“被留区域在左侧”描出，故外环 CCW、洞 CW；
   面积用有符号鞋带公式精确求和（洞为负）。`polygon_area` 也单独公开。

### 精确性口径

- 布尔结果的**拓扑、顶点、面积、集合关系全部是精确有理数**；`result.area`
  / `contour_areas` / `polygons` 不含舍入。测试用手算面积（矩形包含公式、
  三角形积分、容斥恒等式）与独立的 `Fraction` 逐子样本参考核验，期望值不
  由被测实现产生。
- 唯一的 float 出现在 `result.contours`：这是为了能直接喂给沿用
  float 坐标的 `rasterize`/`parse_contours` 管线，交点顶点在导出时才转
  `float`。当操作数坐标是二进制有理（int、1/2、1/4、1/8 网格，本项目栅格
  测试的取法）时，分数交点也常是二进制有理、转 float 精确，回灌栅格化与
  精确参考**逐子样本完全相等**（测试对此专门断言）；需要无损结果时使用
  `result.polygons`。

## 已知限制 / 非目标

- 栅格化仅实现本题契约的数学子集：线段 + 二次 Bézier；**不支持**三次及
  以上 Bézier、圆弧、可变子采样率（固定 4×4）、子像素平移 hinting、
  anti-alias 滤波（覆盖率就是盒子滤波的 k/16）、奇偶(even-odd)规则。
- **布尔运算本轮只接受简单、无洞、仅直线**的轮廓：不接受二次 Bézier、
  自交/自切轮廓、带洞的复合轮廓（题面限定的“两个简单无洞轮廓”范围）。
  不做自交字形、可变形插值、复杂轮廓修复——这些是明确的后续非目标。
- 布尔输入轮廓要求“简单”，而栅格化本身没有该限制：自交轮廓仍可按
  nonzero winding 的数学定义直接栅格化（测试含蝴蝶结自交用例），只是不能
  作为布尔操作数。
- 布尔几何为 `O(E²)` 边对排布；本轮未单列大规模性能指标，20 条互相重叠
  的简单轮廓（每侧约 60~120 边）实测约 0.2~0.3 秒量级，无额外优化。
- 不宣称与任何行业标准（TrueType/OpenType scan-converter、SVG、
  Clipper/Boost.Polygon 等库的具体规则、Porter-Duff 合成等）完整兼容；
  只对本文档描述的契约负责。
- 栅格化在轮廓非常复杂时（段数很多）时间随“子样本行 × 段数”线性增长；
  上限规模（20 条曲边轮廓、64×64）实测亚秒级。

## 演示说明

`python demo.py` 真实运行两部分，无 sleep、无预录结果：

1. 原有栅格化演示：一个 19×13 字形（CCW 曲边外框 + 重叠 CCW 矩形 + CW
   曲边洞），打印灰度图与固定子样本环绕数（普通 +1、重叠 +2、洞内 0、
   外部 0），并触发 NaN 坐标（定位到字段）与 `bool` 冒充画布宽度两类拒绝。
2. 布尔演示：三角形（面积 18）与正方形（面积 36）的并/交/差，手算重叠为
   面积 2 的小三角形，故并=52、交=2、差=16，逐个打印精确面积与 nonzero
   栅格图；再展示**单点相切**边界（并保持两个独立环、交为空集），并实际
   触发两类布尔拒绝：自交蝴蝶结（`SelfIntersectionError`，定位到 `a[0]`
   与冲突边对）和含二次曲线的操作数（`InvalidInputError`）。
